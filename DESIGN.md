# Institute publication design

Readers should be able to identify the finding, check its source, or print the lesson they need. Use the existing Source Serif 4 for reading titles and Inter for navigation, forms and labels. The standard page header and prose column anchor longer pages. Keep diagrams and data tables close to the text that interprets them.

Use the paper, card, ink, rule and accent tokens from globals.css. The teal accent marks links, actions and section labels. Keep print versions black on white. The spacing scale is 4, 8, 12, 16, 24, 32, 48 and 64 pixels. Use the existing rounded controls and visible focus outline. Preserve browser zoom, legible labels, reduced motion and finger-sized controls. Give each screen one descriptive heading and let the content determine its length.
